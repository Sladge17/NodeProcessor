# Описание
Аддон NodeProcessor предназначен для выявления и группирования нод материалов не использующихся в проекте. В процессе использования аддон находит неиспользуемые ноды во всех материалах проекта, и группирует их в стороне от исползуемых нод материала, линкуя их узлы входа с сгенерированными нодами Attribute.
Информация о неисползуемых в проекте нодах публикуется в консоль.

# Установка
Аддон устанавливается через стандартный интерфейс Blender. Нужно пройти по пути Edit > Preferences > Add-ons, и нажав кнопку Install выбрать файл __init__.py в папке NodeProcessor. После этого аддон появиться в панеле инструментов 3D вьюпорта в категории MaterialTools.

# Использование
Для использования аддона NodeProcessor, достаточно нажать клавишу Process useless nodes, находясь на панеле аддона.
