# Описание
Аддон NodeProcessor предназначен для выявления и группирования нод материалов не влияющих на расчёт материалов. В процессе использования аддон находит неиспользуемые ноды во всех материалах проекта, а так-же в группах, и группирует их в стороне от исползуемых нод, линкуя их узлы входа с сгенерированными нодами "Attribute", и оборачивая в фрейм "Useless nodes".
Информация о неисползуемых в материалах и группах нодах публикуется в консоль. Для групп в консоль так-же публикуется список материалов где испольуется описываеммая группа, если такие существуют.

# Установка
Аддон устанавливается через стандартный интерфейс Blender. Нужно пройти по пути Edit > Preferences > Add-ons, и нажав кнопку Install выбрать архив "node_processor.zip" в папке с скаченным репозиторием (по умолчанию "NodeProcessor"). После этого аддон появиться в панеле инструментов 3D вьюпорта в категории "MaterialTools".

# Использование
Для использования аддона NodeProcessor, нужно нажать клавишу "Process useless nodes", находясь на панеле аддона. При необходимости работы с логами аддона, должна существовать консоль ассоциированная с запущенной программой "blender", в которой выполняется работа с аддоном.
